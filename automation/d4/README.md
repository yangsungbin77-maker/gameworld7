# 디아블로4 빌드 플래너 데이터

- `research/*.json` — 직업별 기술 트리 조사 결과(2026-10, 시즌 15 · 증오의 군주 이후). 한글 이름은 인벤 스킬 시뮬레이터·블리자드 한국어 패치노트 기준.
- `build_data.py` — 조사 JSON을 `public/data/d4/<직업>.json` + `meta.json`으로 변환. 실행: `py automation/d4/build_data.py`
- 포인트 규칙(인벤 시뮬레이터 노드 구조 확인): 기술 1~15등급, 업그레이드 1개 = 연결 노드 1 + 업그레이드 1 = 2포인트, 드루이드는 형상을 골라야 변화형이 열림. 한도 83(레벨업 + 시즌 보상).
- 새 시즌에 트리가 바뀌면: research JSON 수정 → build_data.py 실행 → 빌드·배포.
